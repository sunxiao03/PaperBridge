# PaperBridge AI 阅读辅助

## 启用与隐私边界

AI 助读复用“翻译服务设置”中的服务商、HTTPS Base URL、模型和 API Key。API Key 只从 Windows Credential Manager 读取，不保存到 SQLite、日志或 Prompt。

只有用户点击解释、总结或提问后才会调用外部服务。选区任务只发送选中的英文及有界上下文；章节和全文总结按有界分块逐次发送；问答只发送当前问题、最近有界对话和已在本地检索的候选证据。

## 选区解释

在右侧“翻译”页签载入当前页并选中英文，然后切换到“AI 助读”：

- “解释选区”用中文解释术语、逻辑和科学含义；
- “翻译并解释”以“翻译/解释”两部分返回；
- 选区最多 12000 字符，公式、单位、引用和标识符要求保留原样。

完成的选区结果同时保留在“AI 助读—结果”中并打开现有浮窗，方便在阅读位置附近查看。

相同文档版本、选区、上下文、服务商、模型和 Prompt 版本会命中本地缓存。

## 章节和全文总结

“总结当前章节”使用 PDF 目录中当前页所属的章节范围。PDF 无目录时会明确降级为当前页，不会猜测章节边界。

“总结整篇论文”会先显示费用提示并要求二次确认。文档以最多 12000 字符的单元分块总结，再将部分总结分组综合，直到只剩一份结果。中途取消会立即停止后续请求；已完成分块保留在版本化缓存中，下次可复用。

## 当前文献有据问答

问答只建立当前打开文献的本地语料，不检索其他论文，不建立全库向量索引。流程如下：

1. PDFium 逐页提取英文文本，页面完成分块后不继续保留该页的字符坐标对象。
2. PDF 目录为每个分块提供章节标识；无目录时标记为页级降级。
3. 本地 BM25 使用词频、文档频率和分块长度归一化排名。对中文或指代性追问，模型只返回 3–12 个英文检索词；页码不由模型决定。
4. 最多 8 条、24000 字符的候选证据由应用分配 `E1…En`。模型只能使用这些标识回答。
5. 应用逐句验证引用。没有引用、使用未分配标识、事实句未引用或模型自行声称页码时，答案不会被当作有据答案展示。
6. 通过验证的证据卡显示本地 PDF 页码、章节和已提取的英文原文，点击页码可跳转。

“清空”会删除当前标签内的对话上下文。问答消息只在打开的标签内存中保留，关闭标签后不持久化；问答结果也不写入 AI 缓存。

## 资源与请求上限

- 当前文档最多 2000 页、10000000 个提取字符和 10000 个本地分块；
- 总结单元最多 12000 字符、最多 96 个初级分块和 128 次阶段请求；
- AI 助读并发不超过 2，且不超过用户的翻译并发设置；
- 对话最多保留 20 条界面消息，每次只发送最近 6 条；
- AI 缓存最多 5000 条，只保存输入哈希、版本字段、输出和 Token 计数，不保存 Prompt 原文或 API Key；
- 关闭文档、取消任务或更换服务设置会取消所属请求。
