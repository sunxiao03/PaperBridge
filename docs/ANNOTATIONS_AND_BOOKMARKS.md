# PaperBridge 高亮、批注与书签

## 使用方法

1. 打开 PDF，在右侧点击“载入当前页”，然后在已提取的原文框中选中文字。
2. 点击“高亮”、“下划线”或“批注”，选择颜色、填写备注，并决定是否关联当前译文。
3. “书签”用于添加或移除当前页的页级标记。同一篇文献的同一页最多一个书签。
4. 左侧“批注”页签可按类型或失效状态筛选，并可定位、编辑或删除。

PDF 位图本身不提供可靠的 WPF 文本选区，因此选区来自右侧的 PDFium 原文。如果手动修改了原文框，PaperBridge 会拒绝建立锚点并要求重新载入，避免把错误偏移映射到 PDF。

## 锚点和显示

文本标记保存文档内容 SHA-256、页码、原文字符范围、规范化文本指纹、前后文和 PDF 坐标矩形。坐标以页面宽高归一化，覆盖层按当前图像尺寸绘制，所以缩放、页面重渲染和重开文档后仍能定位。切换到段落双语或左右对照时，“定位”会刷新到对应页；切回 PDF 视图后覆盖层仍在原坐标。

关联译文是用户确认时的快照，不会随之后的机器重译或编辑稿自动变化。编辑批注时可以更新或取消关联。

## 验证、迁移与失效

重开文档时，PaperBridge 先比较文档内容哈希，再验证原偏移处的文本指纹并重建坐标。

- 偏移和指纹均有效：标记保持“有效”。
- 偏移已变，但同页只有一处原文匹配：更新偏移和坐标，持久标记为“已安全迁移”。
- 原文消失、出现多次或无法恢复坐标：标记为“已失效”。
- 文档内容哈希变化：标记为“文档已变化”，不把旧坐标套到新内容。

失效项仍保留在列表中，可查看原备注、关联译文和失效原因，也可导航到原页。它们不会继续绘制，从而避免静默错配。

## 存储边界

批注保存在本地 SQLite 的 `document_annotations` 表中，删除文献记录时由外键级联删除。每篇文献最多保存 10000 条标记，坐标矩形每条最多 256 个。批注不写回原 PDF，删除或移动用户原文件不会被批注功能修改。
