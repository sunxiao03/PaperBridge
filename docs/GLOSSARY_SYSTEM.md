# 术语系统使用说明

## 基本规则

术语优先级固定为：个人术语 > 已启用且审核通过的内置术语 > 模型判断。同一层级内先比较词库优先级，再比较词条优先级。待审核和已驳回词条不会发送给翻译服务。

翻译时不会发送整个术语库。PaperBridge 只匹配本次原文及有限上下文中出现的英文术语或英文别名，按最长短语优先选取最多 64 条，并生成确定性版本。词条新增、修改、审核或覆盖会使相关文本使用新的缓存身份；无关词条变化不会让所有缓存失效。

## 管理和审核

在主窗口左侧选择“专业术语管理”：

1. 选择词库并决定它是否参与翻译；
2. 搜索或查看词条的英文、首选中文、类别、来源和审核状态；
3. 对内置起始词逐条“审核通过”或“驳回”；
4. 在个人词库中新增、编辑或删除覆盖项；
5. 需要独立主题时可新建更多个人词库。

随程序提供的 24 条核反应堆物理起始词全部标为“待审核”。它们带有简短解释和来源类别，但不是权威术语标准，必须由使用者审核后才参与翻译。

## 从译文确认术语

翻译结果允许编辑。若要把一次修改保存为个人术语：

1. 在 PDF 原页上选择英文短语；
2. 在译文框选择对应的中文短语；
3. 选择“确认术语…”并检查词条信息；
4. 明确保存后才写入个人术语库。

程序不会从编辑行为中自动学习，也不会批量修改既有词条。

## CSV / TSV 格式

导入文件至少需要以下表头：

```text
english,preferred_chinese
```

完整列为：

```text
english,preferred_chinese,english_aliases,chinese_aliases,category,explanation,notes,source_reference,priority,review_status
```

别名以分号或竖线分隔，`review_status` 可为 `Pending`、`Approved` 或 `Rejected`。缺省审核状态是 `Pending`。导入只允许写入个人词库；相同词库内规范化后相同的英文术语会更新现有词条。导出使用 UTF-8，并对常见电子表格公式前缀进行转义。
