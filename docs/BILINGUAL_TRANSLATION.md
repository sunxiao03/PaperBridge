# 双语阅读与全文翻译

## 显示方式

阅读器顶部提供以下入口：

- `PDF`：返回原始 PDF 页面；
- `段落双语`：按“英文段落—中文译文”显示派生阅读卡片；
- `左右对照`：同一组原文和译文左右排列并按滚动比例联动；
- `浮窗`：在鼠标位置显示右侧栏当前译文或当前双语段落；
- 右侧栏：继续支持单词、选区、句子、段落和当前页翻译。

段落和译文都保留页码及稳定段落标识。选择双语条目会更新当前页映射；上一页、下一页可以在派生视图中导航。

## 版面置信度与降级

PaperBridge 不假设 PDF 文本提取顺序一定等于人类阅读顺序。每页分析：

- 逐字符坐标覆盖率；
- 左右栏的空间分布与纵向重叠；
- 公式和数学符号密度；
- 段落碎片数量；
- 页首、页尾可能接续上一页或下一页的迹象。

置信度达到 72% 且没有检测到多栏时才启用段落对齐。否则自动降级为按页左右对照，并在视图顶部显示原因。降级不是错误；在无法可靠证明段落顺序时，程序不会静默给出精细映射。

## 翻译调度

进入段落或左右对照视图时，程序只排入当前页和后续两页，当前页优先。`翻译本页`只处理当前页。`全文翻译`是可能产生显著 API 费用的显式操作，顺序从当前页开始再覆盖其余页面；可随时取消，已经完成并保存的段落不会回滚。

硬限制如下：

- 等待队列最多 32 页；
- 同时执行最多 2 页；
- 单页最多识别 80 个段落，复杂碎片页改为按页分块；
- 单个翻译块最多 3000 字符；
- 当前派生视图最多装载 200 段；
- SQLite 翻译缓存最多 20000 条；
- PDF 页面和缩略图继续使用 256 MiB / 32 MiB 字节预算缓存。

关闭文档会取消该文档尚未完成的队列工作；更换翻译服务设置会取消使用旧设置的工作。API 请求仍受翻译协调器的去重、并发、超时和分类重试约束。

## 用户编辑保护

每个双语段落分别保存机器译文和用户编辑稿。点击“保存编辑稿”后，后续重新翻译只更新机器层，界面继续展示用户稿并标明“重译不会覆盖”。“对比机器稿”会左右显示最新机器版本和当前编辑稿；点击“恢复机器稿”前会再次确认，只有这项显式操作会删除用户编辑层。

数据库按文档内容哈希隔离译文。PDF 内容发生变化会形成新的文档身份，不会把旧文档的段落编辑静默套用到新内容。
