# ADR-0004：PDF 元数据、目录和缩略图

- 状态：接受
- 日期：2026-08-10

## 决策

导入 PDF 时只在本地执行以下识别：

1. 从 PDF Info 字典读取标题、作者、主题、关键词、创建日期等字段；
2. 提取第一页文本，并使用严格 DOI 模式寻找 DOI；
3. 内置标题有效时优先于文件名；
4. 作者和年份优先使用内置信息；
5. 无可靠来源的期刊字段保持为空，不猜测。

创建日期只作为基础年份候选。后续联网元数据补全或用户编辑可以覆盖，但必须记录来源优先级。

## 目录

目录直接读取 PDFium 书签树，保留父子层级和可解析的页码目标。解析设置以下防御边界：

- 最大深度 64；
- 最多 10,000 个目录项；
- 记录访问过的原生书签地址，遇到循环立即停止；
- 没有直接页码目标的目录项仍可显示，但不提供跳转。

## 缩略图

缩略图复用 PDFium BGRA32 渲染通道，采用 0.26 倍比例和独立的 32 MiB LRU 缓存。只有缩略图标签页当前虚拟化窗口内的页面会发起渲染；列表项回收时释放 WPF 图像。

正文页缓存与缩略图缓存相互独立，预算分别为 256 MiB 和 32 MiB。文档关闭后两者都清空，未完成任务被取消。

## 已知限制

- DOI 启发式只识别标准 `10.<注册机构>/<后缀>` 形式；
- 首页出现多个 DOI 时目前选择第一个；
- 创建日期可能是 PDF 生成日期而非论文发表年份；
- 某些目录使用动作而非直接目标，当前可能无法解析页码；
- 在线 Crossref 补全和元数据人工编辑尚未实现。
