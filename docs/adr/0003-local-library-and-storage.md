# ADR-0003：本地文献库与受管理文件

- 状态：接受
- 日期：2026-08-10

## 决策

文献库采用 SQLite + FTS5。用户导入 PDF 时，程序读取原文件计算 SHA-256，并将副本写入应用受管理目录；不移动、不重命名、不修改原文件。

默认数据根目录为：

```text
%LOCALAPPDATA%\PaperBridge
```

目录结构：

```text
PaperBridge/
  Data/paperbridge.db
  Library/<sha256>.pdf
  Backups/
  Logs/
```

开发、测试和便携性实验可以通过 `PAPERBRIDGE_DATA_DIR` 覆盖根目录。该变量不是密钥配置入口。

## 导入一致性

1. 验证扩展名和 PDFium 可打开性；
2. 流式计算 SHA-256；
3. 查询内容哈希是否已存在；
4. 复制到同目录临时文件；
5. 原子移动为 `<sha256>.pdf`；
6. 插入数据库记录；
7. 失败时清理本次临时文件和未登记的受管理副本。

单个应用实例内的导入串行化，避免两个批量任务同时处理相同文件。重复内容返回已有文献记录，不复制第二份，也不新增数据库行。

## 数据库

数据库启用 WAL、外键、5 秒忙等待和版本化迁移。第一版表保存：

- 文档 ID、内容哈希和受管理文件名；
- 标题、作者、年份、期刊和 DOI；
- 导入时间、最近打开时间；
- 最后页码、滚动偏移和收藏状态。

FTS5 当前索引标题、作者、期刊和 DOI。论文全文索引不属于本次迁移，后续单独设计。

## 恢复和删除语义

阅读位置以零起始页码和列表全局滚动偏移保存，滚动停止 500 ms 后写入，关闭或切换文献时再次写入。

删除功能实现时必须区分：

- 从文献库移除记录但暂时保留文件；
- 永久删除受管理 PDF，必须由用户明确确认。

V1 不删除用户原始导入文件。

## 后续迁移

后续迁移将增加逻辑文件夹、标签、批注、书签、翻译缓存和术语表。任何迁移失败都必须保持旧数据库可恢复，并在发布前加入备份及恢复测试。
