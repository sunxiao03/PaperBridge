# ADR-0002：PDFium 绑定与资源生命周期

- 状态：接受
- 日期：2026-08-10

## 决策

使用 `PDFiumCore` 152.0.7961 作为 PDFium 的直接 .NET 绑定。它以 Apache-2.0 发布，并通过 `bblanchon/pdfium-binaries` 提供目标平台原生文件。

项目自行封装文档、页面、文本页和位图生命周期，不把第三方 Viewer 控件引入 UI。PDFium 全局库按活动文档引用计数初始化和销毁；文档内部操作暂时串行化。

单页渲染输出 BGRA32 像素，单页最多占用 128 MiB。阅读器采用 256 MiB 全局 LRU 原始像素缓存；WPF 可视对象在列表项离开虚拟化窗口后释放。

## 已验证能力

- 打开普通文本层 PDF；
- 获取页数和页面尺寸；
- 提取 Unicode 文本；
- 获取字符在 PDF 用户坐标系中的边界；
- 将页面渲染为 BGRA32；
- 重复打开、提取、渲染和关闭；
- WPF 回收式虚拟列表按需请求页面。

## 限制

- 当前文本块列表尚未实现，只有字符及其坐标；
- 当前文档内的原生调用串行执行，后续通过有界渲染调度器提高吞吐；
- 原生渲染调用开始后不能立即中断，但取消后的结果会被丢弃；
- 文本的物理存储顺序不等于可靠阅读顺序，双栏分析必须另建置信度算法；
- 阶段 0 只支持无密码或调用方提供正确密码的文档，UI 尚未提供密码输入。

## 发布要求

发布包必须保留 PDFiumCore、PDFium 及其二进制来源的许可证和归属信息。升级 PDFiumCore 时必须重新运行固定样本、真实语料、资源循环和自包含发布测试。
