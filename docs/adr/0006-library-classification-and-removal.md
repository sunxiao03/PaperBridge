# ADR 0006：文献分类、标签与移除语义

- 状态：接受
- 日期：2026-08-10

## 背景

PaperBridge 使用受管理 PDF 副本，但分类操作不应改变任何物理路径。文献还需要多标签、收藏和筛选能力，并且“从库中移除”与“永久删除受管理副本”必须具有不同且清晰的结果。

## 决策

- SQLite 数据库版本 2 增加扁平逻辑分类、标签及文献—标签多对多关系；阶段 2 的翻译缓存继续迁移到版本 3。
- 文献最多使用 32 个标签，每个标签最多 40 个可显示字符；分类名称最多 80 个可显示字符，名称按不区分大小写保证唯一。
- 删除逻辑分类时，文献自动回到“未分类”，PDF 文件和标签不受影响。
- 分类、标签和收藏均可在文献库界面编辑，并可按分类、标签和收藏组合筛选；最近打开时间仍作为默认排序依据。
- “从文献库移除”只删除数据库记录并保留受管理 PDF 文件。
- “永久删除受管理副本”需要明确确认；程序先将副本移动到同目录隔离文件，再删除数据库记录，数据库删除失败时恢复文件。用户最初导入的原始 PDF 永不修改。

## 影响

逻辑整理不依赖文件系统目录，也不会因分类变化破坏内容哈希去重。保留受管理文件的移除操作可能产生未被数据库引用的文件，但再次导入相同 PDF 时可以复用该副本。永久删除路径具有明确确认和失败恢复边界。
