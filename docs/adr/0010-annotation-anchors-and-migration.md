# ADR 0010：批注锚点与保守迁移

- 状态：Accepted
- 日期：2026-08-11

## 决策

高亮、下划线和文本批注使用组合锚点：文档 ID 与内容 SHA-256 确认文档身份，页码、字符偏移、规范化原文 SHA-256 指纹和前后文确认文本身份，PDFium 字符坐标合并后的归一化矩形负责绘制。页面书签只使用文档身份和页码。

应用启动或重开文献时重新解析锚点。原偏移指纹不再匹配时，只在同页存在唯一、不区分大小写的原文匹配时自动迁移。无匹配、多义匹配、坐标不可恢复或文档内容哈希改变都必须进入显式失效状态，不继续绘制。“已安全迁移”状态持久保留，相同坐标的重复验证不重写数据库或更新时间。

坐标覆盖层是 PDF 位图上的本地派生层，不修改原 PDF。关联译文是用户在创建或编辑时选择的快照，不是会被后续重译静默改写的动态引用。

SQLite 版本 6 新增 `document_annotations`，对文献删除使用外键级联，并以部分唯一索引保证每页最多一个书签。应用层将单篇文献限制为 10000 条标记。

## 原因

只存页码和固定坐标无法识别 PDF 内容替换，只存文本则无法在重复语句中证明位置。组合锚点能在正常缩放、重渲染和小范围文本位移中稳定定位，同时在无法证明唯一性时停止自动套用。

## 后果

- 用户需从已提取的原文框创建文本标记；编辑过的原文不能用来建立 PDF 锚点。
- 失效批注仍可审计、编辑和删除，但不绘制到页面。
- 保守策略会拒绝一些人工看来可判断的迁移，换取不静默错配的安全性。
- 批注只保存在 PaperBridge 本地数据中，不会出现在用其他 PDF 软件打开的原文件里。
