# ADR 0009：置信度驱动的双语视图与有界页级调度

- 状态：Accepted
- 日期：2026-08-11

## 决策

双语内容是 PDF 的本地派生视图，不修改 PDF 页面。段落映射由 PDFium 逐字符坐标、文本偏移、页码和稳定段落标识组成。只有单栏且置信度不低于 72% 的页面使用段落视图；其余页面保留相同页码映射并降级为按页对照，原因持久化到双语段落记录。

机器译文和用户编辑稿使用不同数据库列。机器重译的 UPSERT 不更新用户列，恢复机器稿必须由用户显式确认。

翻译调度采用页级有界优先队列：当前页优先，自动预取最多后两页，等待上限 32、工作并发 2。全文翻译沿用同一队列，必须由用户启动，取消令牌属于文档/全文批次。单页内部按段顺序调用已有翻译协调器，因此仍共享缓存、请求去重、重试和术语约束。

活动派生视图只读取当前页最多 200 段，已完成的全文结果保存在 SQLite 中按需读取。翻译缓存设置 20000 条上限；渲染位图继续使用已有字节预算 LRU。

## 原因

PDF 的文本顺序在双栏、公式、浮动图表和跨页段落中经常不可靠。将无法证明的精细映射降级为页级关系，比展示无提示的错误对齐更符合科研阅读需求。页级调度可以控制内存、API 并发和关闭文档时的取消范围。

## 后果

- 复杂页仍可按页阅读译文，但不会伪装成可靠段落对齐；
- 全文翻译可能产生显著 API 费用，因此不自动启动；
- 切换标签不会销毁已打开文档的全文任务，关闭文档或更换服务设置会取消它；
- 当前版本的精细映射粒度是页内段落，不尝试重排图表、脚注或公式内部结构。
