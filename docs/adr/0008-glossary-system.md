# ADR 0008：本地多词库、显式审核与相关术语约束

- 状态：Accepted
- 日期：2026-08-11

## 决策

术语库和词条存入同一个本地 SQLite 数据库，数据库版本提升到 4。词库记录来源、启用状态、主题和优先级；词条记录英文规范形、首选译名、双语别名、分类、短解释、备注、来源、优先级、审核状态和更新时间。

解析采用确定性顺序：用户来源高于内置来源，随后比较词库优先级、词条优先级、更新时间和稳定标识。只有已启用词库中的 `Approved` 词条可用。相关术语匹配使用英文词边界和别名，最长短语优先，每次最多注入 64 条。

缓存中的术语版本由实际命中的解析后词条生成，而不是使用全库版本。这样既保证相关术语修改后不会复用旧译文，也避免无关主题词条使所有翻译缓存失效。

内置词条只提供小批量待审核种子，不以自动生成数量作为质量指标。用户编辑译文后必须选择原文和译文并显式确认，系统不得静默学习。

## 原因

该方案保留未来安装多个专业词库的空间，同时使个人译名始终可解释地覆盖内置值。审核门槛和来源字段避免未经确认的批量词条直接影响专业翻译；相关匹配则限制 Prompt 大小、隐私暴露和 API 成本。

## 后果

- 阶段 4 的段落和全文翻译可复用同一解析与缓存身份；
- 修改审核状态会改变相关请求的术语版本；
- 删除或禁用词库不会删除已有翻译缓存，但后续请求不会命中使用旧术语版本的结果；
- 内置词条的专业权威性仍需项目所有者人工确认。
