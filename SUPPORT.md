# Support

PaperBridge is a personal, best-effort project. It has no SLA, hosted service, paid support, or guaranteed compatibility with every PDF or OpenAI-compatible endpoint.

Before reporting a problem:

1. Verify the archive hash against `SHA256SUMS.txt`.
2. Read `KNOWN_LIMITATIONS.md` and `PRIVACY.md`.
3. Reproduce with a non-confidential, preferably synthetic PDF.
4. Record Windows version, PaperBridge version, provider type, operation, and the exact error message with secrets removed.

Never attach an API key, Credential Manager export, private database, log containing confidential text, or a copyrighted/restricted PDF without permission.
